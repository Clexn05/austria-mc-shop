# Austria-MC Shop v4

Cloudflare-Workers-Shop für Austria-MC mit D1, Adminbereich und automatischer Rang-Freischaltung über AustriaShopBridge.

## Enthalten

- Austria-MC Shop im Alpen-/Minecraft-Stil
- Hintergrund ohne Spieler-Skins und ohne Coin-Shop
- Ränge dynamisch aus Cloudflare D1
- Checkout für PayPal / paysafecard / Klarna vorbereitet
- Bestellstatus
- geschütztes Adminpanel unter `/admin/`
- Ränge, Preise, Prefix, Farbe und Rechte verwalten
- Bestellungen ansehen
- Testkäufe ohne echtes Geld anlegen
- D1-Tabellen im Admin lesen
- Admin-Zugang ändern
- Fulfillment-API für AustriaShopBridge
- `/api/health` zur Diagnose

Die konkrete Einrichtung steht in **START-HIER.md**.
