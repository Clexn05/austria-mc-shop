Kostenlosen Testkauf starten

Erzeugt absichtlich eine Bestellung mit PAID + PENDING. Es wird kein Geld abgebucht.

Was passiert?

  1. D1 erhält eine Testbestellung.
  2. payment_status = PAID
  3. fulfillment_status = PENDING
  4. AustriaShopBridge holt sie ab.
  5. LuckPerms setzt die gekaufte Gruppe.
  6. Der Auftrag wird auf FULFILLED gesetzt.

Falls der Rang ingame nicht sofort sichtbar wird, einmal neu joinen.

Sicherheit

Die Admin-Seite verwendet eine signierte, HttpOnly-Session. Das Passwort wird nicht im Klartext in D1 gespeichert.

Die drei Bootstrap-Secrets in Cloudflare dienen nur für die erste Einrichtung bzw. eine Wiederherstellung.
